Keyboard

    

      
⌘KSearch everything, run a command or recipe

      
/Filter the list

      
j kNext / previous session

      
rWrite a message to the session

      
.Recipes for the session (or the selection)

      
tType straight into the terminal (Ctrl+] to stop)

      
`Switch chat ⇄ terminal (when they share a place)

      
\Move the terminal: bottom → right → top → shared with chat → hidden

      
gGroup by inbox / project

      
lLive board of everything working

      
dDiscover: repos worth forking, the idea lab and your plans

      
nNew session

      
fSwitch herdr to this pane (or open a Codex app thread in the app)

      
yCopy a link to this session

      
xClose (asks first)

      
s or ⌘-clickAdd to the selection, to send to or close several at once

      
1–9Switch machine tab (1 is All)

      
[ ]Collapse the list / the terminal

      
cClosed sessions

      
EscClear the filter, then the selection

    

    
Decisions (i)

    

      
j k or ↓ ↑Next / previous decision

      
1–9Pick that option on the focused card

      
yYes: the allow / yes / recommended option; on finished work, Looks good

      
nNo: the deny / no option; on finished work, Send back (opens the reply, prefilled)

      
vVerify now (finished work)

      
rReply in your own words (Enter sends, Esc closes)

      
o or EnterOpen the session

      
s or xSkip it for now without answering

      
uBring back the last skipped one

      
f / ⇧FNext / previous filter (All, Quick ones, Permissions, Questions, Done?)

      
EscClose the reply box, then leave Decisions

    

    
Filter words must all match; -word excludes. is:stale, is:dup, is:working, agent:codex also work.
